# よく使うアプリを Scriptable なしで開く（ショートカットのウィジェット）

LAUNCHER（Scriptable）のタイルは、タップすると一瞬 Scriptable を経由します（iOS の仕組みで避けられません）。
よく使うアプリは、iOS 標準の「ショートカット」ウィジェットに置くと、**タップで直接開きます**。
使い分けの目安：よく使う 4〜8 個 → ショートカットのウィジェット／それ以外 → LAUNCHER。

## 1. アプリごとにショートカットを作る
ショートカットアプリ → 右上の「＋」で、アプリ 1 つにつき 1 つ作ります。

1. アクションを検索して **「App を開く」** を追加 → 青い「App」をタップして開きたいアプリを選ぶ
2. 上の名前をタップ →「名称変更」で名前を付ける（例：`Notion`）
3. 同じメニューの「アイコンを選択」で色と記号を選ぶ（白基調に近づけるなら、色は灰色系がおすすめ）

- STUDYMANAGER のような Web ページは、「App を開く」の代わりに **「URL を開く」** に `https://weekly-from3rd-party.github.io/StuMane/` を入れる
- LAUNCHER の選択肢で ⤳（ショートカット経由）のアプリ用に作ったショートカット（名前＝日本語名）は、ここでもそのまま使えます

### 2 個目からは複製で（1 個 30 秒ほど）
1. 作ったショートカットを長押し →「複製」
2. できたもの（名前の末尾に「1」）を長押し →「名称変更」で新しい名前に
3. タップして開く → 「App を開く」の青いアプリ名をタップして別のアプリに変える → 完了
4. 必要なら長押し →「詳細」→ アイコンで記号を変える（色は複製元と同じままで統一できる）

## 2. フォルダにまとめる
1. ショートカットアプリの左上「＜」で一覧に戻る →「ショートカット」の画面で右上のフォルダの「＋」→ 名前を **「ランチャー」**
2. 作ったショートカットを長押し →「移動」→「ランチャー」
3. フォルダの中で長押ししてドラッグすると並べ替えられます（ウィジェットの並びもこの順）

## 3. ウィジェットを置く
1. ホーム画面の何もないところを長押し → 左上の「編集」→「ウィジェットを追加」→ **ショートカット**
2. サイズを選ぶ：**中＝4 個／大＝8 個**（小は 1 個）
3. 置いたウィジェットを長押し →「ウィジェットを編集」→ フォルダ：**ランチャー**

これで、タイルをタップするとアプリが直接開きます。

## 4. LAUNCHER と並べる
- LAUNCHER 側は、▶ →「アプリを編集」でセットを作り（例：`その他`）、ショートカットのウィジェットに入れなかったアプリだけを入れる
- LAUNCHER のウィジェットを長押し →「ウィジェットを編集」→ Parameter にそのセット名

## うまくいかないとき
- **タップするとショートカットアプリが開く**：アクションが「App を開く」1 つだけになっているか確かめる（ほかのアクションがあると、ショートカットアプリが開くことがあります）
- **ウィジェットに出ない**：ウィジェットの「フォルダ」が「ランチャー」になっているか確かめる

# iPad のウインドウ表示で、後ろに Scriptable を残さない（試験的）

LAUNCHER のウィジェットに Parameter `閉じる` を入れると、タイルをタップしたときにショートカット「ランチャー」が呼ばれます。
「ランチャー」は、いったんホーム画面に移動して（Scriptable などのウインドウを画面から外して）から、目的のアプリを開きます。

## ショートカット「ランチャー」を作る
ショートカットアプリ →「＋」→ 名前を **「ランチャー」**（この名前ちょうど）にして、次の順にアクションを足します。

| 順 | アクション | 設定 |
|---|---|---|
| 1 | **ホーム画面に移動**（「ホーム」で検索） | なし |
| 2 | **URL を開く**（「URL を開く」で検索） | 青い「URL」をタップ →「ショートカットの入力」を選ぶ |

- 入力が受け取れないと言われたら：ショートカットの「ⓘ（詳細）」で、入力の種類に「テキスト」と「URL」が入っているか確かめる
- アプリが開かないときは、1 と 2 の間に **待機**（1 秒）を足す

## ウィジェットに設定する
LAUNCHER のウィジェットを長押し →「ウィジェットを編集」→ Parameter に `閉じる`（セット名と一緒なら `勉強,閉じる`）

## 注意
- 開く流れは「Scriptable → ショートカット → ホーム画面 → アプリ」になるので、前より少し遅くなります
- ショートカット経由のアプリ（「アプリを開く N」）は、ショートカットがもう一度呼ばれるので、ショートカットアプリのウインドウが残るかもしれません。まずは Notion や YouTube など URL で開くアプリで試してください
- うまくいかなければ、Parameter から `閉じる` を消すと元に戻ります
