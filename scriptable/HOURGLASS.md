# 砂時計（HOURGLASS）の準備

iOS の時計アプリのタイマーと砂時計ウィジェットを、ショートカット「砂時計」1 つで同時に始めるための手順です。

## 1. Scriptable にスクリプトを入れる
1. Scriptable で右上の「＋」から新しいスクリプトを作り、`hourglass-widget.js` を全文貼り付ける
2. スクリプト名を **「砂時計」** にする（下のショートカットで名前を選ぶので、別の名前でもかまいません）

## 2. ショートカット「砂時計」を作る
ショートカットアプリ → 右上の「＋」→ 名前を **「砂時計」** にして、次の順にアクションを足します。
アクション名は iOS のバージョンで少し違うことがあります。検索欄に括弧内の言葉を入れると見つかります。

| 順 | アクション | 設定 |
|---|---|---|
| 1 | メニューから選択（「メニュー」） | 項目を 4 つ：`6:00 まで`／`25 分`／`分を入力`／`停止` |
| 2 | 「6:00 まで」の中に **テキスト** | `6:00` |
| 3 | 「25 分」の中に **テキスト** | `25` |
| 4 | 「分を入力」の中に **入力を要求**（「入力」） | 種類：数字、質問：「何分？」 |
| 5 | 「停止」の中に **テキスト** | `停止` |
| 6 | メニューの外（「メニューの終わり」の下）に Scriptable の **Run Script**（「Scriptable」） | Script：砂時計／Parameter：**メニューの結果**／「Run In App」は**オフ** |
| 7 | **もし**（「if」） | 入力：Run Script の結果、条件：「次より大きい」0 |
| 8 | 「もし」の中に **タイマーを開始**（「タイマー」） | 時間：**Run Script の結果** 分 |

- 「6:00」の代わりに `7:30` など別の時刻を入れても使えます（次に来るその時刻まで）
- 「停止」はウィジェットの記録だけを消します。**時計アプリのタイマーは、時計アプリで止めてください**（ショートカットからタイマーは止められません）

## 3. ウィジェットを置く
- ロック画面：長押し →「カスタマイズ」→ ロック画面 → ウィジェット欄 → Scriptable → 長方形か円形 → タップして Script に「砂時計」
- ホーム画面：小・中・大
- Parameter：寝た姿勢で見るなら `左` か `右`（砂時計と残り時間を 90 度回す。残り時間は 30 分刻みのドット数字）。ホーム画面の暗色は `dark`

## 4. 使い方
- ウィジェットをタップするとショートカット「砂時計」が開くので、時間を選ぶ
- 時計アプリのタイマーと砂時計が同時に始まる
- 残り時間の数字は秒まで正確に動く。砂の量は、iOS がウィジェットを描き直すたびに進む（砂 1 粒ぶんごと・最短 5 分おきに頼んでいる）

## うまくいかないとき
- **タイマーが始まらない**：手順 6 の「Run In App」がオフか、手順 8 の時間が「Run Script の結果」になっているか確かめる
- **砂時計が始まらない**：手順 6 の Script が、貼り付けたスクリプトの名前になっているか確かめる
- **時計アプリでタイマーを止めた**：ショートカットで「停止」を選ぶと、砂時計も待機に戻る
