# 砂時計（HOURGLASS）の準備

iOS の時計アプリのタイマーと砂時計ウィジェットを、ショートカット「砂時計」1 つで同時に始めるための手順です。

## 1. Scriptable にスクリプトを入れる
1. Scriptable で右上の「＋」から新しいスクリプトを作り、`hourglass-widget.js` を全文貼り付ける
2. スクリプト名を **「砂時計」** にする（下のショートカットで名前を選ぶので、別の名前でもかまいません）

## 2. ショートカット「砂時計」を作る
ショートカットアプリ → 右上の「＋」→ 名前を **「砂時計」** にして、次の順にアクションを足します。
アクション名は iOS のバージョンで少し違うことがあります。検索欄に括弧内の言葉を入れると見つかります。

| 順 | アクション | 設定 |
|---|---|---|
| 1 | メニューから選択（「メニュー」） | 項目を 5 つ：`終わる時刻を選ぶ`／`6:00 まで`／`25 分`／`分を入力`／`停止` |
| 2 | 「終わる時刻を選ぶ」の中に **入力を要求**（「入力」） | 種類：**時刻**、質問：「何時に終わる？」 |
| 3 | その下に **日付をフォーマット**（「フォーマット」） | 日付：「入力を要求」の結果、日付のフォーマット：**カスタム**で `H:mm` |
| 4 | 「6:00 まで」の中に **テキスト** | `6:00` |
| 5 | 「25 分」の中に **テキスト** | `25` |
| 6 | 「分を入力」の中に **入力を要求** | 種類：数字、質問：「何分？」 |
| 7 | 「停止」の中に **テキスト** | `停止` |
| 8 | メニューの外（「メニューの終わり」の下）に Scriptable の **Run Script**（「Scriptable」） | Script：砂時計／Parameter：**メニューの結果**／「Run In App」は**オフ** |
| 9 | **もし**（「if」） | 入力：Run Script の **Output**、条件：「**に値がある**」 |
| 10 | 「もし」のすぐ下（「その他の場合」より上）に **タイマーを開始**（「タイマー」） | 時間：**Output** 分 |

- 手順 9 で入力が「ファイルサイズ」と出たときは、その青い文字をタップ →「**Output**」そのものを選び直す（「ファイルサイズ」の指定を外す）。そのあと条件を「に値がある」にする
- スクリプトは、開始したときだけ分を返し、「停止」や読めない値のときは何も返しません。だから「値がある」ときだけタイマーが始まります
- 「その他の場合」の中には何も入れない（「その他の場合」は消してもよい）

- **「終わる時刻を選ぶ」で、終わりの時刻を毎回自由に選べます**（時計のホイールで選ぶ）。次に来るその時刻まで、例えば今が 23:00 で 6:30 を選べば翌朝 6:30 まで
- 「25 分」のテキストは `25` でも `25分` でも動きます（`1時間`・`1.5時間` も可）
- 手順 3 のフォーマットを忘れても動くようにしてあります（「午前 6:30」「2026/10/07 6:30」のような形もそのまま読めます）
- よく使う時刻は、「6:00 まで」と同じように固定の項目として足せます（テキストに `7:30` など）
- 「停止」はウィジェットの記録だけを消します。**時計アプリのタイマーは、時計アプリで止めてください**（ショートカットからタイマーは止められません）

## 3. ウィジェットを置く
- ロック画面：長押し →「カスタマイズ」→ ロック画面 → ウィジェット欄 → Scriptable → 長方形か円形 → タップして Script に「砂時計」
- ホーム画面：小・中・大
- Parameter：寝た姿勢で見るなら `左` か `右`（砂時計と残り時間を 90 度回す。残り時間は 30 分刻みのドット数字）。ホーム画面の暗色は `dark`

## 4. 使い方
- ウィジェットをタップするとショートカット「砂時計」が開くので、時間を選ぶ
- 時計アプリのタイマーと砂時計が同時に始まる
- 残り時間の数字は秒まで正確に動く。砂の量は、iOS がウィジェットを描き直すたびに進む（砂 1 粒ぶんごと・最短 5 分おきに頼んでいる）

## うまくいかないとき
- **タイマーが始まらない**：手順 6 の「Run In App」がオフか、手順 8 の時間が「Run Script の結果」になっているか確かめる
- **砂時計が始まらない**：手順 6 の Script が、貼り付けたスクリプトの名前になっているか確かめる
- **時計アプリでタイマーを止めた**：ショートカットで「停止」を選ぶと、砂時計も待機に戻る
