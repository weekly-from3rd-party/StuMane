# HABIT の通知（習慣ごとに時刻を決めて鳴らす）

## 1. Scriptable で時刻と方式を決める
Scriptable で HABIT を ▶ →「習慣を編集」→「通知を設定する」→ 習慣を選ぶ → 時刻（例：`22:00`）→ 方式を選ぶ。

| 方式 | 記録済みの日 | 手間 |
|---|---|---|
| Scriptable の予約 | たまに鳴ることがある（下の注） | ここで終わり |
| ショートカットのオートメーション | 鳴らない | 下の 2. を時刻ごとに 1 回 |

- 通知をタップすると、その習慣の今日の記録がつきます
- 時刻を空にして「決定」すると通知を外せます
- 注：予約の方式は、ウィジェットや Scriptable が動くたびに 7 日先まで組み直し、記録済みの日の通知を外します。記録したあとしばらく何も動かないと、その日の分が残って鳴ることがあります。7 日以上ウィジェットが一度も動かないと止まります

## 2. オートメーションを作る（オートメーションの方式を選んだ習慣だけ）
1. ショートカットアプリ → 下の「オートメーション」→ 右上の「＋」
2. **「時刻」** → 時刻を Scriptable で決めた時刻に／「毎日」／**「すぐに実行」** を選ぶ →「次へ」
3. 「新規の空のオートメーション」→ アクションを検索して Scriptable の **「Run Script」** を追加
4. 「Script」をタップして HABIT のスクリプトを選ぶ
5. 「Parameter」に **習慣の名前**（例：`読書`）を入れる → 完了

- 同じ時刻の習慣はまとめられます：Parameter に `読書,勉強` のようにカンマ区切り
- 「実行時に通知」はオフにすると、余計な通知が出ません
- 習慣の名前を変えたら、Parameter も同じ名前に直してください

## うまくいかないとき
- **通知が来ない**：設定 → 通知 → Scriptable →「通知を許可」がオンか確かめる
- **オートメーションの方で毎回確認が出る**：オートメーションを開いて「すぐに実行」を選び直す
